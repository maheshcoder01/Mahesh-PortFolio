# Mahesh Bharat Bellale — Portfolio

A responsive, dependency-free portfolio site for software developer opportunities.

## Run locally

Double-click `run-site.bat`, or open PowerShell in this folder and run:

```powershell
python -m http.server 4173
```

Then open http://localhost:4173. The site can also be opened directly from `index.html`.

The contact form opens the visitor’s default email app with their message details prefilled. It does not send or store messages on this site. The resume PDF is available from the navigation and hero buttons.
